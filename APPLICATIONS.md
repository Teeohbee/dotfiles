| | |
|---|---|
| **Why** | Lightweight companion to Claude Code for visual browsing, quick edits, and diffs. Opens instantly, uses a fraction of VS Code's memory. |

| **Source** | [zed-industries/zed](https://github.com/zed-industries/zed) |
